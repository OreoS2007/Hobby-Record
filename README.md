# Hobby Record

見た・読んだ本、映画、漫画、アニメ、ドラマ、ゲームを記録するシンプルな Web アプリです。
`index.html` 1ファイルだけで動き、サーバーは不要です。

## 機能
- 作品名で検索すると、タイトル・作者・表紙・あらすじ・ジャンル・公開日（連載・放送期間つき）を自動で入力
- 評価（★）、状態、鑑賞・読了日、感想の記録
- 種類・ジャンルでの絞り込み、検索、並べ替え

## データの保存について
記録はあなたのブラウザ内にだけ保存され、このリポジトリや他人には送られません。
変更のたびに、次の場所へ即時に保存します。

1. ブラウザの localStorage
2. ブラウザの IndexedDB（①が消えても復元できます）
3. 任意：「自動保存ファイルを選ぶ」で指定した JSON ファイル（Chrome / Edge）

入力途中の内容も自動保存され、閉じてしまっても再開できます。
ブラウザのサイトデータを消すと①②は失われるため、「書き出し」や自動保存ファイルでのバックアップをおすすめします。

## 検索元
Google Books / AniList / iTunes Search API / Wikipedia（日本語版）/ TMDB（任意）

TMDB を使うには、ご自身の API キーを画面の「⚙ TMDBキー」から設定してください（キーはブラウザ内にのみ保存されます）。
